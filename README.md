# SchoolHub — Next Level HTML/CSS/JavaScript

This version is a polished browser-based School Management System UI built with three separate files:

- `index.html`
- `style.css`
- `script.js`

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Included
- Responsive desktop/tablet/mobile layout
- Dashboard with KPI cards and charts
- Student, teacher, academics, attendance, exams, finance, inventory, library, communication, events, documents, reports and settings screens
- Working navigation
- Global student search
- Add-record modals
- Demo actions and toast notifications
- Notification drawer
- Dark/light mode with localStorage
- Mobile sidebar
- Demo data

## Important
This remains a frontend/browser prototype because it is intentionally limited to separate HTML/CSS/JavaScript files. It does not contain a real PostgreSQL database, Express API, Prisma layer, or production authentication. Those require a backend.
